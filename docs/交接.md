## 技术参考

### 架构
- 单文件 `index.html`，无构建；`icon.png` 是主屏幕图标；`.nojekyll` 让 Pages 不走 Jekyll。
- IndexedDB 库 `class-log`（同域名下还有 chat-lite，各用各的库；不用 localStorage）：
  - store `incidents`：一条记录一个文档，key = id；字段 student / cls / type / date / what / did / result / done / createdAt / updatedAt。
  - store `settings`：key `main` → `{ escalateAt, classes: [三个], updatedAt }`；key `roster1` / `roster2` / `roster3` → `{ names: [按学号顺序], regulars: [常客名字], updatedAt }`，按设置里第几个班存（改班名不丢名单）。
- 备份 JSON：`{ app: 'class-log', version: 1, exportedAt, settings, rosters: { roster1, roster2, roster3 }, incidents: [{ id, ... }] }`（rosters 只带导过的班）。导入记录按 id 合并，同一个 id 留 updatedAt 新的，不删已有的；名单每个班 updatedAt 新的那份赢，老备份没有 rosters 就跳过。

### 部署
- Cloudflare 后台 → Workers & Pages → 创建 → Pages → 连接到 Git → 选 `cloudxuan1/class-log`，项目名填 `class-log` → 框架 None、构建命令留空、输出目录 `/` → 保存并部署。
- 部署好后进项目 → 自定义域 → 填 `classlog.cloudxuan1.com`。DNS 本来就在 Cloudflare，记录会自动加，一两分钟就通。
- main → 正式网址 `https://classlog.cloudxuan1.com/`；其他分支自动出预览 `https://<分支别名>.class-log.pages.dev`（别名 = 分支名小写、非字母数字换成 `-`）。push 后一两分钟生效。
- 每个网址的 IndexedDB 互不相通：预览打开是空本子，别在预览上记真事；正式只认 classlog.cloudxuan1.com 一个（`class-log.pages.dev` 也能打开同一个站，但数据不通，别用它记）。pages.dev 要是分到的子域名不一样，预览网址以实际为准，同步改 CLAUDE.md 和这里。
